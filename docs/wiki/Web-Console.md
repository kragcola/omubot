# 管理端

Vue 3 / TypeScript / Vite 管理应用由同一 Python 服务提供静态资源。页面调用原有业务 owner，不直接读写数据库、不自行发送 QQ，也不建立另一个配置体系。

## 日常入口

| 入口 | 管理内容 | 需要核对 |
| --- | --- | --- |
| 运行概览 / 管理 | 核心状态、配置应用、受管任务 | 实际运行版本、连接、忙碌与失败原因 |
| 模型配置 | 命名模型及任务绑定 | 完整目的地、密钥引用、保存/运行差异 |
| 人格设定 | 人格、设定与受控应用 | 角色版本与固定 Canon，不混入学习事实 |
| 权限管理 | 精确范围、期限、撤权与保护管理 | 身份、动作、目标与用途；配置不代授权 |
| 离线试聊 | offline 模式下的模拟对话 | 不能作为 QQ 实际送达证据 |
| QQ 接入 | 连接、身份、登录与依赖状态 | 连接成功不等于账号在线或聊天通过 |
| 用量与诊断 | 动作、模型、成本与错误 | unknown、未结算和缺失指标不能当成功或零 |
| 业务管理页 | 记忆、事项、关系、知识等已有 owner 的管理 | 来源、版本、审批和撤回状态 |

当前页面应以实际实例提供的菜单与功能为准；列出业务入口不表示对应模型、外部服务或实机质量已验收。

## 会话与权限

admin 和 status 会话分别管理，status 只读。管理请求保留同源与会话验证，浏览器不持久保存明文凭据。实例之间不共享 cookie 身份。

保存配置与在线授权分开；权限变更沿原 Policy / 取消机制生效。应用配置后会生成新的核心和管理会话，旧 cookie 不应被当成新一代认证。

开发用认证绕过仅限获准的本机 offline 环境，不能与 live 模式混用；公开部署不能借开发便利关闭门禁。
