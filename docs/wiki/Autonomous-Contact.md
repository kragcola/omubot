# 主动联系

允许有理由的闲聊或角色生活分享，但必须先有具体对象、真实来源与明确授权。主动联系不是自动打开自由发言。

## 双授权与真实对象

群内主动联系同时需要该群和实际拟联系用户的独立授权；缺任何一级都不能发送。每次都有真实对象，不能借别人授权虚构联系对象。同一事件按群合并，避免向同群多人重复播报。

内容可以是获准范围内的自主闲聊或生活分享。角色生活来源需要已提交的 Story / Schedule 等状态，不能编造生活事件来凑触发机会。

## 有界择时

真实候选与合法窗口出现后，由原 Thinker 在共享预算内作一次“现在 / 延后 / 放弃”判断并记录安全理由码。关系、性格、角色关切与故事可参与选择，但不能自行提高产品上限、刷新来源期限或绕过静默窗。

延期在原候选和原期限内管理，不轮询模型、不无限重试。事项到期不额外生成自动联系计时器，也不因生成了一句承诺就取得发 QQ 权限。

## 实际发送仍走原出口

候选有效、双授权有效、业务窗口允许、模型获准、QQ 保护与发送预算允许，都要成立。提及实际用户的首泡还核验独立 mention 权限；后续泡不能借首泡检查跳过各自的发送门。

旧来源失效或撤权时取消其未发行为，已经花费的动作成本与实际发送事实保留。未知结果停发，不靠换账号继续。

## 当前状态

本地原生候选、择时、期限和发送路径已有检查；真实有限测试中，双授权合法开启后未出现原生候选，因此未验证择时或带 @ 的实际主动联系。现有证据不足以归因，不能把“无候选”记作 bot 自主放弃。

当前固定长窗关闭 Contact，只验证普通对话。后续需独立保留候选 hook、历史/来源门与实际接收证据，不能重放失败输入强行补齐。
