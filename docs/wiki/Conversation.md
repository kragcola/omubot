# 对话

目标是回答当前问题并保持角色一致，让上下文、工具与表达为回应目的服务。是否回复、回复内容、如何分段以及实际送达是不同环节。

## 一轮对话

可信入站经过会话归属、参与与完整性判断，建立当前轮次，冻结人格、配置和有效上下文。Thinker 与模型使用共享预算；必要工具结果回到原回复路径。最终内容经表达组织、发送准入和 Actions，成功接收的内容才按可见事实处理。

一个会话慢模型不应无界阻塞所有会话。同群最终提交有序；新消息、撤权或版本变化可以使旧轮次失效。取消后的迟到生成不能继续提交，已发送前缀不能从历史中假装消失。

## 分段与情感节拍

分段不能只按句号切，也不能把连续感叹号切成独立消息。局部字词可以作为有意节拍，但整组应表达完整、无无故前导空行，不能为了数量删尾或重发。

例如，激动场景可以有“没 / 错 / 就 / 是 / 这样！！！”这样的局部碎片；这属于允许的组织形式，不是要求每次激动都机械发五条。

已批准的新安装合同最多五个独立气泡、整体 105 秒，保留原准备、准入、实际发送起组的分阶段期限和目标间隔。每个实际 QQ 写仍消耗一次成本；旧保存设置不因新默认自动扩大。自然节拍的选择与实收效果要独立验证。

当前本地原生五泡路径已通过；实机普通场景只有有限样本。流式、规划后发言等路径在当前固定候选测试中关闭，不能拿完整文本的验证替代未知尾文、撤权和取消验证。

## 不回复如何判断

依次区分参与策略、输入完整性、账号保护、权限、轮次失效、模型/工具失败、期限和投递终态。不能把所有沉默归为模型选择，也不能因账号在线就认定程序必须回复。

评价时要同时读实际内容：有没有回答问题、主体是否清楚、人格是否一致、原因是否有据、尾部是否完整。程序成功与气泡数量都不能单独证明聊天合格。
