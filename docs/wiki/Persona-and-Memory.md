# 人格与记忆

固定人格、真人事实、学习偏好、临时情绪与角色虚构生活承担不同职责。不能将它们混成一份不断被模型改写的提示词。

## 数据分域

| 域 | 用途 | 边界 |
| --- | --- | --- |
| Persona / Canon | 角色是谁、稳定设定与行为边界 | 受控版本，不因一句聊天自动改写 |
| 真人事实 | 有来源的用户或群内信息 | 主体、scope、用途和证据有效，不补未知原因 |
| 黑话 / 表达 | “是什么意思”“怎么说” | 与事实及人格分离，有候选、审核与修订 |
| 当前上下文 / 短窗 | 本轮或近期承接 | 原期限不续期，不把临时感受固化成性格 |
| 受限事项 | 尚未完成的具体事与条件 | 来源、时间、有效状态、取消与终态明确 |
| Story / Schedule / Dream | 明确虚构的角色生活与计划 | 与真人事实隔离；Dream 保持人工提案、审核流程 |

当前范围还包括知识、图谱和识别相关 owner，但它们的代码存在不证明真实数据质量、外部识别服务或长期使用已通过。

## 教导、纠正与审核

教学输入按当前权限、来源和用途进入对应流程。称呼的窄即时入口只接受本人明确、非敏感的同群指令；第三人外号只可用于本轮理解，不改对方首选称呼，也不承诺长期记住。角色名纠正需要现有角色证据与审核流程，不能把未确定的识别当作永久正确答案。

已应用记录应能修订、取消或失效，并在之后合法、相关的对话中消费。重复教学不是无限提高可信度，隔一段时间再问也不能靠延长过期来源制造“记住了”。

超出角色行为或权限的指令，不因被称为教学而改写固定人格、获得工具权限或变成长期执行规则。关系熟悉度与事实可信度也不能代替授权。

## 当前限制

事实、黑话与表达、事项和相应管理流程已有批准代码闭环。实机事项检测只证明有限提议、审核、应用、消费与取消，并保留回复主体含混的负例。

经历抽取的真实质量保持未通过；当前不继续调用经历模型，不放宽证据与隐私校验。自动抽取、自动应用、原文留存与跨域共享是分别管理的权限，不能因其他记忆功能可用而一起开启。
