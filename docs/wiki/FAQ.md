# 常见问题

## 现在 clone GitHub 能拿到新版吗？

可以取得当前运行候选对应的新版源码：Python 核心、前端、锁文件、通用配置和必要构建检查。完整开发测试、内部记录和个人运行资料不包含在内；当前尚未通过生产验收，也没有发布生产就绪安装包。

## bot 在线为什么没回复？

在线只是账号/连接的一部分证据。还要看参与判断、输入完整性、保护 held、授权、来源、期限、轮次失效、模型与工具失败以及实际投递。缺证时不能随意归因为模型“不想说话”。

## 开了功能就可以发消息吗？

不能。开关、依赖就绪、业务资格与动作授权分开。主动联系还要实际用户和群双授权，并受原窗口、限频及成本约束。

## 情绪和好感度会自动放宽权限吗？

不会。方案 B 只允许情绪参与最终表达消费，关系调整分寸与语境。它们不能授予模型、工具或 QQ 权限，也不能自动提高联系上限。

## 分成五条才算自然吗？

不是。五泡是获准输送合同的上限与特定表达能力，模型应按目的选择节拍。连续感叹号保持完整，局部碎片允许，整组仍要完整；少泡与多泡都需阅读实际效果。

## 为什么不照搬旧插件平台？

成品首先需要可靠的角色聊天和状态衔接。新版按实际 owner 与生命周期增长，已有窄工具与扩展合同；没有真实需求就不建立通用总线、万能 Context 或插件市场。

## 是否已经比旧版更好？

结构与门禁已按新目标重建，体验优势仍要证明。旧版是使用体验基准，局部文字样本、测试数量或架构说明不能代替完整比较与验收。

## 如何判断第三阶段结束？

需要实机业务结果、实际接收与回复质量、配置/保护/清理、恢复、平台及长期合同的相应证据。当前仍有失败、阻断和未验，阶段三未通过，真实反馈阶段尚未开始。
